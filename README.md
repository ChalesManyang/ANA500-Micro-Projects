# ANA500 – Data Science Micro-Projects

**National University | Master of Science in Data Science**

**Student:** Charles Ayuk  
**Course:** ANA500 – Data Science  
**Programming Language:** Python

## Project Overview

This repository contains four micro-projects completed as part of ANA500 at National University. The projects demonstrate the application of Python programming, data preparation, exploratory data analysis, data visualization, machine learning, and deep learning techniques.

Each project focuses on a different stage of the data science process, progressing from preparing and understanding data to developing predictive models and interpreting results.

## Micro-Project Descriptions

### Micro-Project 1: Data Preparation Using NumPy and Pandas

**Objective:** Apply Python's NumPy and Pandas libraries to organize, explore, and prepare data for analysis.

**Key Activities:**
- Import and inspect the dataset.
- Examine data types and dataset structure.
- Identify missing values and potential data quality issues.
- Clean and organize data using Pandas.
- Prepare the dataset for further analysis.

**Data Science Process:** Steps 1–2, ending at Prepare.

**Tools:** Python, NumPy, Pandas, Jupyter Notebook.

[View Micro-Project 1](./Micro-Project-1)

### Micro-Project 2: Data Visualization and Exploratory Analysis

**Objective:** Use Python visualization libraries to explore data, identify patterns, and communicate meaningful findings.

**Key Activities:**
- Explore relationships between variables.
- Create charts and graphs using Python.
- Examine patterns in airline passenger satisfaction and flight delays.
- Interpret visualizations to identify potential areas for improvement.
- Present findings using appropriate visualization techniques.

**Data Science Process:** Steps 1–4, ending at Report.

**Tools:** Python, Pandas, Matplotlib, Seaborn.

[View Micro-Project 2](./Micro-Project-2)

### Micro-Project 3: Machine Learning Regression

**Objective:** Apply machine learning regression techniques to predict numerical outcomes and evaluate model performance.

**Key Activities:**
- Prepare numerical and categorical variables for modeling.
- Develop regression models, including Linear Regression and Support Vector Regression (SVR), as applicable.
- Train and evaluate predictive models.
- Compare model performance using appropriate regression metrics.
- Interpret findings and discuss potential applications.

**Data Science Process:** Steps 1–5, ending at Act.

**Tools:** Python, Pandas, NumPy, Scikit-learn, Matplotlib.

[View Micro-Project 3](./Micro-Project-3)

### Micro-Project 4: Deep Learning Regression

**Objective:** Explore the application of artificial neural networks to regression problems involving continuous numerical predictions.

**Key Activities:**
- Prepare and preprocess data for deep learning.
- Develop a neural network regression model.
- Train the model using an appropriate optimization approach.
- Evaluate predictions using suitable regression metrics.
- Interpret results and identify potential improvements.

**Methods:** Deep learning, artificial neural networks, regression.

**Tools:** Python and applicable deep learning libraries, such as TensorFlow/Keras.
